# Network Protocol Documentation

This section provides detailed, evidence-backed analysis of the various network protocols used by the Guild Wars 2 client.

## Protocols

*   **[Game Server Protocol](./game/):** The primary protocol for real-time gameplay (`gs2c`/`c2gs`).
*   **[Login Server Protocol](./login/):** The initial authentication protocol (`ls2c`/`c2ls`).
*   **[Platform/Portal Server Protocol](./portal/):** The protocol for account-wide services and the trading post (`ps2c`/`c2ps`).
*   **[Web API Protocol](./web_api/):** The bridge between the C++ client and the embedded web browser.
